# PAIRO · 电脑与手机配合使用的 AI 助手

把电脑上的画面分享给手机，在手机上向 AI 提问，再把回答显示回电脑。你可以用它查看共享资料、理解截图，或整理自己说出的问题。

**普通使用者下载 Windows 程序和 Android 安装包即可，不需要安装编程工具，也不用运行命令。**

## 使用前准备

- 一台 Windows 电脑和一部 Android 手机，先连接到同一个可信的 Wi-Fi 或家庭网络。
- 电脑和手机都安装本版本程序，连接期间保持电脑程序打开。
- 如果想让 AI 回答，另需你所使用的 AI 平台提供的 **API 地址、模型名称和 API Key**。这些信息不是由本项目提供的，是否收费以该平台为准。

没有 API Key 也能先配对、查看画面和接收截图；填写模型配置后才能获得 AI 回答。

## 第一步：打开电脑程序

1. 下载上面的 EXE，放在你能正常保存文件的文件夹，例如“文档”中的 `PAIRO` 文件夹。
2. 双击 EXE。它是便携程序，无需安装向导；首次打开需要解压运行文件，可能稍慢。
3. 程序会在 EXE 旁创建 `PAIRO-data` 文件夹，保存非秘密设置。以后移动程序时，可以把这个文件夹一起移动。

Windows 程序目前未做数字签名。如果系统提示“未知发布者”，先确认文件来自本项目的版本下载页，再按系统提供的选项启动；受单位管理的电脑请按单位的安装要求操作。

## 第二步：安装手机程序

1. 用手机打开上面的 APK 下载链接，下载完成后打开该文件。
2. 如果 Android 询问是否允许该浏览器或文件管理器安装应用，按系统提示允许此次来源，然后完成安装。不同品牌手机的提示文字可能不同。
3. 打开 **Pairo Meeting Copilot**，它会直接进入“手机端”。

这是可侧载使用的测试安装包，还没有上架应用商店。它不会要求手机共享屏幕。

## 第三步：让手机连接电脑

1. 在电脑上点击 **“开始屏幕分享”**，选择要分享的屏幕或窗口。只想分享画面时，可先取消勾选“同时发送麦克风音频”。“共享系统音频”默认关闭，需要声音时再勾选。
2. 在电脑的 **“连接手机”** 区域找到 **“手机端信令地址（同一局域网）”** 和 **“一次性房间码”**。
3. 在手机的“配对桌面”区域，填写这两个信息，点击 **“连接”**。
4. 等待出现 **“P2P 已加密直连”**。此时手机应能看到电脑正在分享的画面；需要听声音时，在手机上点击 **“开启声音”**。

“信令服务地址”就是帮助两台设备找到彼此的连接地址。它通常长这样：`http://192.168.1.23:8787`。这是格式示例，**请填写你电脑实际显示的地址**。

电脑上的本机地址通常包含 `127.0.0.1`，保留默认值即可；手机请使用“手机端信令地址”，不要把电脑的本机地址填到手机里。端口不一定是 `8787`，请把显示的整段地址一起复制。

## 第四步：填写 AI 设置

在手机的 **“模型配置”** 区域填写：

| 界面字段 | 它是什么 | 怎么填写 |
| --- | --- | --- |
| OpenAI-compatible API 地址 | AI 服务接收问题的地址 | 从服务商文档复制完整的 Chat Completions 地址；通常以 `/v1/chat/completions` 结尾，不能填普通聊天网页的地址 |
| 模型名称 | 要使用哪一个 AI 模型 | 填服务商给出的准确名称；要分析截图，需要该模型支持图片输入 |
| API Key | 允许程序调用你账号下 AI 服务的密钥 | 从服务商获取后粘贴到这里，不要分享给别人 |

“OpenAI-compatible”表示接口格式兼容，能否使用取决于服务商和模型。本程序不是 AI 服务本身。

API Key 只用于当前打开的手机页面，**不会保存**；关闭或重新打开应用后通常需要再填。API 地址和模型名称会保存在设备上。

## 第五步：试着问一个问题

建议第一次先手动操作，确认整条流程可用：

1. 在电脑打开想查看的资料，并确认它出现在共享画面中。
2. 点击电脑上的 **“截图”**，或按 `Alt + Shift + S`。
3. 手机收到截图后，在“问题与回答”下方输入，例如：“请概括这张图里的主要内容。”
4. 点击输入框旁的 **↑** 发送。AI 回答会显示在手机上，并同步到电脑的 **“手机 AI 回复”** 区域。

如果希望收到截图或语音问题后自动提问，可以勾选手机上的 **“收到问题后自动请求模型”**。实时视频不会持续自动发送给 AI；模型处理的是你发送的截图、转写问题或手动提问。

### 电脑快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Alt + Shift + S` | 截取当前共享画面并发给手机 |
| `Alt + Shift + M` | 开始或停止语音识别，把识别出的文字发给手机 |
| `Alt + Shift + A` | 开启或关闭手机自动回答 |

Windows 程序会尝试注册全局快捷键；如果被其他程序占用，请用界面按钮操作。语音识别是否可用取决于运行环境，输入文字和截图提问不依赖语音识别。

### 结束使用

电脑点击 **“停止”** 会结束本次分享并关闭采集；手机点击 **“断开当前房间”** 会退出配对。离开房间、切换设备角色或点击“清空”，会清除截图和对话上下文，并使未完成的 AI 回答失效。重新开始分享时，请使用新房间码。

## 遇到问题怎么办

| 现象 | 可以先检查什么 |
| --- | --- |
| 下载链接打不开或出现 404 | 登录 GitHub，并确认账号有私有仓库的访问权限；也可从版本下载页的 Assets 下载 |
| 手机连接不上 | 确认两台设备在同一网络、电脑程序仍开着、地址和房间码抄对；手机不要填写 `127.0.0.1` 或 `localhost` |
| 电脑显示多个手机连接地址 | 优先选择当前 Wi-Fi 或网线连接的地址；可在 Windows“设置 → 网络和 Internet”里查看该连接的 IPv4 地址，与程序显示的地址对应 |
| 一直停在“正在协商”或“connecting” | 访客 Wi-Fi 可能禁止设备互相访问；换到可信家庭网络。VPN、代理或防火墙也可能影响连接。Windows 首次询问网络访问时，在可信网络按需允许此应用，不必关闭整个防火墙 |
| 配对成功但没有画面 | 确认电脑仍在分享、没有在选择窗口时取消；可以停止后重新选择共享来源 |
| 画面有了但没有声音 | 手机点击“开启声音”；电脑确认勾选了所需音频并允许麦克风。系统音频能否捕获还取决于系统和共享来源 |
| 截图到了，AI 没有回答 | 自动回答默认关闭；先填写 API Key，并手动输入问题发送，查看页面上的错误信息 |
| 提示模型服务错误或请求超时 | 检查手机联网、完整 API 地址、模型名称、密钥和服务商账号状态；截图问答还需要支持图片的模型 |
| API Key 重新打开后没了 | 这是预期行为：密钥不保存，重新填写即可 |
| Android 提示应用无法更新 | 测试包可能使用不同签名。可先记录非秘密设置，卸载旧版后安装新版；卸载会清除手机上的设置 |

当前版本主要面向同一个可信网络内使用。手机与电脑不在同一网络时，可能需要额外配置中转服务；高级部署方式见 [部署说明](docs/DEPLOYMENT.md)。

## 你的数据会去哪里

- 分享的画面、声音和设备之间的消息通过加密连接在电脑和手机之间传输。配对服务只帮助建立连接，不保存会议内容；局域网配对信息本身仍使用明文连接，请在可信网络使用。
- 发起 AI 提问时，相关文字和附加截图会从手机发送给你配置的 AI 服务商。接收实时画面本身不会自动把整段视频上传给 AI。
- API Key 不发送给配对服务，也不会写入本项目的偏好配置文件。
- 语音识别可能使用浏览器供应商的在线服务，使用前请确认场景允许分享、录音和转写。
