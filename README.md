# PAIRO Meeting Assistant · 把会议提示留在手机上

PAIRO 是一个同时在电脑和手机上使用的会议助手。电脑负责问题采集、模型调用、上下文和本地知识库，把回答实时同步给手机；手机用于配对和提词阅读。

你可以把它当作一份不断更新的发言提示：会议投屏留在电脑，回答留在手边的手机。准备完成后，电脑端可以收进右下角托盘，使用快捷键操作，不会自动弹出回答或朗读。

**当前正式版：v0.5.0，协议 5。** 电脑负责模型、上下文和本地知识库，手机用于提词阅读；电脑与手机必须同时更新到本版，早期 0.5.0 开发构建也需更新。

## 2. 先把电脑和手机连起来

### 先准备网络

让电脑和手机连接同一个 Wi-Fi。也可以用手机开热点，让电脑连接这个热点。电脑与手机要能在这个局域网内互相访问。

程序里的“上位机”指电脑，“下位机”指手机。

### 在电脑上操作

1. 打开 PAIRO，进入底部的 **“投送窗口选择”**。
2. 选择会议模式。想识别自己和会议对方的声音，选 **“会议助手”** 并按需启用麦克风；只识别电脑里播放的会议对方声音，选 **“一对一会议”**。
3. 点击 **“开始屏幕分享”**，在预览中选择要分享的窗口。选择单个窗口，便于控制截图会包含哪些内容。
4. 进入 **“房间配对”**，保留电脑显示的二维码，供手机扫描。如果有多个连接地址，选择当前 Wi-Fi 或网线对应的那个。

### 再在手机上操作

1. 打开 PAIRO，进入 **“房间配对”**。
2. 点击 **“扫码配对”**，允许相机权限，扫描电脑二维码。
3. 扫码填好信息后，点击 **“连接”**。
4. 回到电脑，确认是自己的手机，点击 **“允许此手机”**。
5. 两端显示 **“P2P 已加密直连”**，就配对成功了。

无法扫码时，也可以把电脑显示的手机连接地址和房间码手动填到手机。地址要完整复制，包括最后的端口号；手机不要填写 `localhost` 或 `127.0.0.1`，它们指向手机自身。

## 3. 在电脑上设置 AI

进入电脑底部的 **“会议助手设置”**。这三个信息都由你使用的 AI 服务商提供：

| 要填写什么 | 到哪里找 / 怎么填 |
| --- | --- |
| API 地址 | 复制服务商给出的完整聊天接口地址，通常以 `/chat/completions` 结尾 |
| 模型名称 | 复制服务商提供的准确名称，按原样填写 |
| API Key | 在服务商后台创建并复制访问 Key，只填写到应用里 |

填好后，点击 **“测试 AI 配置”**。测试成功后，在同页的 **“电脑提问”** 输入一个简单问题，点发送，先确认能收到回答。

要让 AI 看截图，所选模型还需要支持图片输入。文字测试成功后，可以再用截图试一次。测试和提问可能计入服务商用量；PAIRO 本身不提供 AI 额度。

Key 只在电脑本次运行的内存中，不通过 P2P 发给手机，也不会保存为下次启动的设置，重新启动应用后需要再次填写。分享截图或报错信息时，请遮住 Key；不需要把 Key 发到仓库、Issue 或聊天中。

## 4. 开始使用会议助手

**两端需要同时使用这次的 0.5.0 新构建（协议 5）。** 旧的 0.5.0 构建也需更新；版本不兼容时会提示两端升级。

先在电脑 **“快捷键设置”** 中启用快捷键。使用右侧小键盘时，请开启 **Num Lock**；没有小键盘，可以在这里改成自己方便的组合键。

| 默认按键 | 按下后会发生什么 |
| --- | --- |
| **小键盘 Num1** | 截取已选窗口的当前画面，交给电脑模型回答，结果同步手机；默认问题是“请回答图中的问题。” |
| **小键盘 Num2** | 开启或关闭语音转文字；识别出的文字在电脑自动提问 |
| **小键盘 Num3** | 在其他程序选中文字后按下，复制本次选区，在电脑自动提问，结果同步手机；无需打开电脑主窗口 |
| **Shift + 小键盘 Num3** | 手机回答完成后，先点击电脑里需要填写的输入框，再按此键，逐字键入电脑本地最新一条完整回答 |
| **↑ / ↓** | 上下滚动手机的回答区域 |

**第一次使用语音**：在电脑“快捷键设置 → 本机离线语音”选语言和模型，点击 **“下载离线语音组件”**。界面会显示还需下载多少；已有组件可复用。完成后按 Num2。普通话会议可选“中文”，中英交替可选“自动识别”；若术语仍不准确可尝试高质量档，电脑转写积压时可选均衡或轻量档。识别在停顿或一段话结束后进行，只将通过本机人声和转写检查的文字用于提问。

系统声音与麦克风分别识别，同时发言时各自排队；同一音轨中的多人重叠仍可能识别不全。自动模式会参考同一音源最近两段明确的长句语言，帮助识别短答；“不”等单音节仍可能识别错误。处理容量不足时会提示并暂停收听，处理完已接收片段后可重新开启；可改用轻量档或减少同时发言的音源。

**准备好后收起电脑端**：点击“收起到托盘”，或关闭主窗口。PAIRO 仍在后台运行。选中文字、按 Num3、在手机阅读回答即可，电脑不会自动弹窗或播放回答。

**需要把回答填回电脑时**：等待手机回答全部完成，点击问卷等程序中要填写的普通输入框，再按 **Shift + Num3**。无论这条回答来自选中文字、截图还是语音，都可以使用。它只键入最新一条完整回答，不会自动提交表单；输入前先确认光标位置，输入后检查内容。回答生成中、失败、取消或清空后不会沿用旧回答。

默认速度是中文 **60 字/分钟**、英文 **90 词/分钟**。在电脑 **“快捷键设置 → 回答键入速度”** 可分别修改并保存；英文按每词 5 个字符折算，混排分别计时。换行和制表符转为空格，避免代按回车提交。目标程序处理较慢时实际速度也可能降低。

键入途中按 **Esc** 或再次按 **Shift + Num3** 可停止；切换窗口、换到其他输入框、断开连接或关闭快捷键也会停止。Esc 只在等待回答／键入期间临时占用。不支持密码框、只读框、管理员权限窗口，以及未开放可编辑信息的自定义控件；停止前已填入的文字会保留，请自行检查。

方向键会被会议快捷键占用。如果还要用其他软件的 ↑/↓，先换一组快捷键，或暂时关闭会议快捷键。按键发生冲突时，程序会提示并保留此前可用的设置。

手机的 **“会议助手”** 页面只用于阅读；电脑“会议助手设置”可手动提问、取消、清空或修正配置后重试。手机显示排队、生成中、完成、取消或失败状态，未完成内容不会用于键入。向上阅读时，新回答不会强行把页面拉到底部。需要实时查看电脑画面、听电脑声音时，展开底部的 **“一对一会议 · 查看电脑画面与声音”**，再点“开启声音”。


## 5. 使用电脑知识库

1. 先完成电脑 API 配置，再打开 **“知识库”**，阅读并勾选内容发送说明。
2. 点击 **“添加本地文件夹”**，用系统窗口选择一个具体的项目或文档目录。
3. 点击目录的 **“导入 / 更新 / 重试”**。电脑提取原文、分块，并使用已配置的模型理解和总结；页面展示处理进度、成功、跳过和失败原因，可随时取消。
4. 展开文件查看每个片段的摘要、原文节选和来源编号。文件修改后点击更新，只重新理解内容或模型配置发生变化的文件；被移走的文件会从索引移除。重启后索引仍可用，中断文件可重试。
5. 提问时电脑先进行本地词语与来源匹配。命中时将最相关片段送入同一次回答请求，并在手机显示参考来源；没有足够匹配时按通用知识直接回答，不额外调用远程分类。简短的“那它呢”等追问可沿用上一问题的资料。使用明确的项目名、术语或文件名能改善命中；这不是跨语言语义检索。截图中的文字不会先被本地检索识别，可在“截图后自动提问”中写明项目名或术语。

支持 UTF-8 文本、Markdown、常见代码、JSON/YAML/TOML、CSV、HTML/XML、DOCX 和 ODT。PDF、图片、旧版 DOC、加密文件暂不支持，请导出为支持格式。文本单文件最多 1 MB 且 12 万字，DOCX/ODT 最多 4 MB；最多 10 个目录、每目录 600 个文件、全库 1500 个片段，索引文件最多 24 MB。较大的目录请缩小范围。

默认排除 `.git`、依赖/构建目录、明显凭据文件、链接和二进制。仍请先自行移除无关或敏感内容；选中文档的内容会发给配置的模型服务，摘要与原文片段保存在电脑的 `PAIRO-data/knowledge-base/store.json`（普通非便携运行时为应用用户数据目录）。不执行文档中的代码或命令。移除目录或文件只删除索引，不修改原文件；下次更新会重新发现单独移除的文件。删除原文件后，应更新索引，以清除旧内容。

## 6. 换窗口、结束会议与更新

- **只换要分享的窗口**：电脑点击“更换共享内容”，手机不用重新扫码。
- **更改声音来源或会议模式**：停止共享，修改选项后重新选择分享来源，沿用当前房间。
- **暂停语音提问**：再按一次 Num2。
- **暂停共享**：电脑点击“停止共享”，立即释放画面和声音，手机清除旧画面；房间、已批准连接和提词保留。再次开始分享时沿用房间，取消选择也会保留房间。已提交的 AI 请求可继续完成。
- **结束会话**：电脑在配对页点“结束会话”，或从托盘选择“退出并结束会话”；手机也可点“断开当前房间”。这会断开房间并清除本次提词。关闭电脑主窗口会收进托盘，共享会继续。
- **更新软件**：先结束会话并从托盘退出电脑程序，再替换 EXE，或完整解压新 ZIP；保留旁边的 `PAIRO-data` 文件夹。手机打开新 APK 覆盖安装。电脑与手机都更新到同一版本。

## 遇到问题时先看这里

| 遇到什么 | 先检查什么 |
| --- | --- |
| 手机连不上电脑 | 两台设备是否在同一个 Wi-Fi / 手机热点；电脑程序是否仍在运行；手机地址是否从电脑完整复制。可点“检测电脑连接” |
| 扫码时无法打开相机 | 到手机“设置 → 应用 → PAIRO → 权限”允许相机，再回到应用扫码 |
| AI 配置测试失败 | 核对服务商给出的完整地址、模型名称、Key，以及服务余额和电脑网络；按应用提示修改 |
| 收到截图却没有正确回答 | 检查模型是否支持图片、截图中问题是否清晰，以及电脑显示的错误提示 |
| 按快捷键没有反应 | 先开始分享并连接手机，再启用会议快捷键；检查 Num Lock、按键冲突，或换成组合键 |
| 按 Num3 没收到新问题 | 先确认两端版本、连接与快捷键已启用，再在原程序选中文字；没有选区时不会使用旧剪贴板内容 |
| Shift + Num3 没有键入 | 等手机回答完成，先点击普通可编辑输入框；查看电脑主窗口“投送窗口选择”底部的状态。两端需同时更新；Esc 被占用时不会开始 |
| 语音没有变成文字 | 确认离线组件已下载、有实际声音来源，并已按 Num2；说完停顿片刻再看手机 |
| 离线组件下载失败 | 确认电脑能访问 GitHub 和 Hugging Face，程序所在目录可写，再重试 |
| 转写跟不上或内容听错 | 纯普通话或纯英语可选对应语言。高质量档适合可以等待的场景，积压时可切回均衡或轻量。也可以在电脑提问栏手动输入 |

## 内容会去哪里？

- 电脑画面和声音通过加密的 P2P 连接传给你允许加入的手机。
- 语音在电脑本机转成文字，中文结果统一为简体；音频不发给外部语音转写服务。
- 提问时，问题文字和相应截图会发给你在电脑上配置的 AI 服务。持续播放的画面不会逐帧送给 AI；语音和文字提问也不会自动夹带上一次截图。
- Num3 只在按下时读取选区。程序优先直接读取所选文字，必要时模拟一次复制并尝试恢复剪贴板；不连续记录键盘文字。Shift+Num3 使用电脑内存中的最新完整回答，键入你选择的输入框，不在电脑界面展示或写入设置、日志。
- 系统音频可能包含其他软件的声音，使用前请关闭无关播放；想限制截图范围，选择单个窗口。
- `PAIRO-data` 保存本机运行设置和缓存；离线转写的临时音频完成或取消后清理，异常退出留下的工作文件在下次启动清理。连接诊断不包含 Key、地址、房间码或对话内容。

仓库隐私检查见 [检查记录](docs/PRIVACY_REVIEW_2026-10-16.md)。当前主要面向同一可信局域网；另一网络／多网卡组合的完整真机验收，以及 Windows 代码签名仍在 [待办](docs/TODO.md) 中。

需要开发、修改或自行打包，见 [开发指南](docs/DEVELOPMENT.md)。本版新增能力、已知问题和验收边界见 [v0.5.0 发布说明](docs/releases/v0.5.0.md)。旧版界面说明见 [v0.2.0 指南](docs/USAGE_v0.2.0.md)。
