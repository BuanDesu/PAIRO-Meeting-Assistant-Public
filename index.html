版本与更新

点击“检查新版本”会向 GitHub 查询正式版本，不需要填写密钥。私有仓库请在浏览器登录后查看发布页。

更新前先结束会话；下载同一版本的 EXE 和 APK。电脑关闭旧程序后替换 EXE，保留旁边的 PAIRO-data 文件夹；手机打开新 APK 覆盖安装。0.1.0 调试包首次迁移到正式签名需按 README 指导操作。
