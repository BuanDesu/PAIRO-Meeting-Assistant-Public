# v0.2.0 使用指南（已发布版本）

把电脑上的一个窗口或整个屏幕分享给手机，在手机上向 AI 提问，再把回答显示回电脑。它适合查看共享资料、理解截图，或整理自己提出的问题。

**下载电脑程序和手机安装包即可使用，不需要安装编程工具或运行命令。** AI 服务需要你自己提供；没有 API Key 也可以先连接、看画面和接收截图。

## 使用前准备

- 一台 Windows 电脑、一部 Android 手机，连接同一个可信的 Wi-Fi；也可以让电脑连接手机开启的热点。
- 电脑和手机都安装同一版本，使用期间保持电脑程序打开。
- 想使用 AI 时，从你的 AI 服务商取得 **API 地址、模型名称、API Key**。API Key 类似调用服务的密码，请在手机应用内填写；服务可能收费，以服务商为准。

## 第一步：打开电脑程序

使用单文件 EXE：放在可正常保存文件的文件夹，例如“文档”中的 `PAIRO` 文件夹，然后双击。程序每次启动会先解压运行文件，通常需要等待几秒。

使用目录 ZIP：先完整解压，保留目录里的文件，再双击 `Pairo Meeting Copilot.exe`。不要只把目录中的 EXE 单独取出来。

两种方式都会在程序旁创建 `PAIRO-data` 文件夹，保存地址、模型等非秘密设置。以后移动程序时，把设置文件夹一起移动。无法写入该位置时，会使用系统中的个人配置目录。

Windows 程序目前未做数字签名。如果系统提示“未知发布者”，请先确认下载来源是本项目的版本页；受单位管理的电脑按单位的安装要求操作。

## 第二步：安装手机程序

1. 用手机下载 APK，下载完成后打开该文件。
2. 如果系统询问是否允许浏览器或文件管理器安装应用，按提示允许此次来源，完成安装。
3. 打开 **Pairo Meeting Copilot**，直接进入手机端。

这是可自行安装的 APK，尚未上架应用商店。手机只接收电脑画面，不需要共享自己的屏幕。

**从 v0.1.0 首次升级：**旧包使用调试签名，新包改为固定正式签名。如果系统不允许直接更新，请先记录电脑地址、API 地址、模型名称等设置，卸载旧版再安装。卸载会清除手机设置；API Key 需重新填写。以后的正式版本使用同一签名，可以直接覆盖安装。

## 第三步：连接电脑与手机

1. 电脑点击 **“开始屏幕分享”**，在缩略图中选择要分享的 **整个屏幕** 或 **单个窗口**。只想展示一份资料时选它所在的窗口。
2. 声音按需开启：麦克风会弹出本次使用的权限确认；“共享系统音频”用于发送电脑播放的声音。拒绝麦克风仍能分享画面。
3. 电脑在“连接手机”中显示二维码。若有多个地址，选择当前 Wi-Fi 或网线对应的地址；不要选不相关的 VPN 或虚拟网卡。
4. 手机点击 **“扫码配对”**，允许相机，扫描二维码。扫码只填写地址与房间码，核对后点击 **“连接”**。二维码有效期 10 分钟，过期可在电脑刷新。
5. 电脑确认申请来自你的手机，点击 **“允许此手机”**。
6. 两端显示 **“P2P 已加密直连”** 后，手机应出现画面。要听声音，点击手机上的 **“开启声音”**，并检查设备音量。

不能扫码时，可手动填写电脑显示的手机连接地址和房间码。“信令服务地址”就是帮助设备找到彼此的连接地址，例如 `http://192.168.1.23:8787`。这是格式示例，请填写电脑实际显示的完整地址，包含端口。

电脑自身的 `127.0.0.1` 地址保留默认值即可；手机不能用它，应填写局域网地址。扫码被拒绝且不再询问时，在手机“设置 → 应用 → PAIRO → 权限”重新允许相机，再返回扫码。

## 第四步：填写并测试 AI 设置

在手机“模型配置”填写：

| 字段 | 含义与填写方法 |
| --- | --- |
| OpenAI-compatible API 地址 | 从 AI 服务商文档复制完整的 Chat Completions 接口地址，通常以 `/chat/completions` 结尾；不能填普通聊天网页地址 |
| 模型名称 | 服务商给出的准确名称；分析截图需要支持图片的模型 |
| API Key | 从服务商取得的密钥，仅在当前手机应用会话中使用 |

“OpenAI-compatible”表示接口格式兼容。PAIRO 是连接和提问工具，AI 回答来自你配置的服务商。

点击 **“测试 AI 配置”**，先确认文字请求成功。测试会发送一条简短文字，可能计入服务商用量；文字测试通过后，再用截图确认模型支持图片。

地址和模型名称会保存，**API Key 不保存**。关闭或重新打开手机应用后，需要再次填写 Key。它不会发送给电脑的配对服务。

## 第五步：发送截图并提问

1. 在电脑确认当前分享内容是你想发送的资料。
2. 点击 **“截图”**（`Alt + Shift + S`）发送当前共享画面；或点击 **“区域截图”**，框选需要的部分，再点“发送所选区域”。
3. 传输达到 100% 后仍会等手机确认。出现 **“手机已确认收到截图”**，才表示手机已经能显示图片。
4. 在手机输入问题，例如“请概括这张图里的主要内容”，点击 **↑**。
5. 回答会逐步显示，完成后同步到电脑“手机 AI 回复”区域。想取消当前等待，点击 **“取消等待”**；失败时先修正配置或网络，再点 **“重试上次失败的问题”**。

区域截图只裁剪这一次发送的图片；实时画面仍分享此前选中的整个屏幕或窗口。要调整实时分享范围，用 **“更换共享内容”** 选择新窗口。更换时房间、手机连接和对话保持，取消选择会继续原来的分享；改变声音设置时需停止后重新开始。

手机收到的截图会附在后续问题中，不需要时点击附件旁的 **×** 移除。勾选 **“收到问题后自动请求模型”**，会自动提交收到的截图或转写问题；实时视频不会持续自动上传给 AI。

### 快捷键与结束使用

| 快捷键 | 操作 |
| --- | --- |
| `Alt + Shift + S` | 发送当前共享画面的截图 |
| `Alt + Shift + M` | 开始或停止语音识别，将识别文字发给手机 |
| `Alt + Shift + A` | 开启或关闭手机自动回答 |

快捷键被占用时，用界面按钮操作。语音识别是否可用取决于运行环境；文字和截图提问不依赖它。

电脑点 **“停止”** 结束分享并关闭采集；手机点 **“断开当前房间”** 退出。离开房间、切换设备角色或“清空”会清除截图及对话上下文，并取消未完成的 AI 回答。重新开始分享时使用新的房间码；只换窗口时用“更换共享内容”，无需重扫。

## 更新版本

点击页面底部 **“版本与更新”** 查看当前版本，可以手动检查新版本，或打开发布页下载。私有仓库无法匿名查询时，在浏览器登录 GitHub 查看；程序不要求填写 GitHub 密钥。

更新前先结束会话，同时下载同一版本的电脑程序和 APK。电脑关闭旧程序后替换文件，保留 `PAIRO-data`；目录版保留设置文件夹并完整解压新目录。手机打开新 APK 覆盖安装。v0.1.0 首次迁移按上面的签名说明操作。

## 遇到问题怎么办

| 现象 | 可以先检查什么 |
| --- | --- |
| 下载 404 或打不开 | 登录有私有仓库访问权限的 GitHub 账号，从 Releases 的 Assets 下载 |
| 手机连接不上 | 同一网络、电脑程序仍打开、地址包含正确端口；手机不要填写 `127.0.0.1` 或 `localhost`，可点击“检测电脑连接” |
| 等待电脑允许 | 在电脑核对申请并点击“允许此手机” |
| 一直正在协商 | 访客 Wi-Fi 可能禁止设备互访；VPN、代理或防火墙也可能影响。首次网络访问提示时，按需允许此应用访问可信网络，无需关闭整个防火墙 |
| 连接后没画面 | 检查分享是否仍在进行，使用“更换共享内容”重新选择正确窗口 |
| 有画面但没声音 | 手机点击“开启声音”；检查两端音量及电脑的声音选项，麦克风需允许权限 |
| 网络短暂断开 | 等待程序有限重试；仍失败时使用“重新连接”。地址变动后刷新电脑地址和二维码，再配对 |
| 截图到了但没有 AI 回答 | 自动回答默认关闭；先填 Key、测试配置，再手动输入问题发送 |
| 模型错误或请求超时 | 检查完整 API 地址、准确模型名、密钥、手机联网与服务商账号；修正后点击重试 |
| Key 重开后没了 | 这是预期行为，密钥只用于当前会话，重新填写即可 |
| APK 不能更新 | 首次从 v0.1.0 调试包迁移需记录设置、卸载后安装；以后若仍失败，请核对安装包来自本项目 |

排查连接时，点击 **“连接诊断”**，复制信息附到问题描述。诊断只包含版本、连接状态和轨道数量，不含 Key、地址、房间码、画面或对话。

## 数据会去哪里

- 画面、声音及设备间消息通过加密连接在电脑和手机之间传输；配对服务只帮助建立连接，不保存会议内容。局域网配对信息仍是明文连接，请使用可信网络。
- 提问时，相关文字、对话上下文和附加截图从手机发送给你配置的 AI 服务商。看实时画面本身不会自动把整段视频上传给 AI。
- API Key 不发送给配对服务，不写入本项目的偏好配置。
- 语音识别可能使用浏览器供应商的在线服务，请确认当前场景允许分享、录音和转写。

当前主要面向同一可信网络使用。跨网络可能需要额外配置中转服务，见 [部署说明](DEPLOYMENT.md)。
