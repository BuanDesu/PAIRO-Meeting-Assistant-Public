# 公开源码迁移说明

2026-10-28，本仓库从维护者的旧私人源仓库迁移而来。迁移保留 7 个分支、4 个历史版本标签及完整提交父子关系。个人邮箱改为维护者在 GitHub 设置中确认的隐私地址；旧验收文档中的设备型号、一次性房间码和个人日程描述已泛化。第三方作者、许可证与归属信息保留。

历史重写会改变提交和标签对象 ID，原提交签名不能作为新对象的签名。旧验收文档中的提交缩写、PR、CI 和发布链接记录旧源仓库当时的事实，不是本公开仓库新提交的验证证据。旧仓库保持私有且未改写，平台 PR 引用、Actions 日志/附件、旧 Releases、缓存和外部副本没有因此清除。

本次迁移提供源码，未迁移旧 Releases 的二进制附件或签名材料，也未将旧附件标记为从新提交构建。4 个版本标签保留作源码历史；目前没有公开安装包。发布新版安装包时，应从最终公开源码重新构建，执行该精确提交的 CI 与版本/摘要验证，并使用真实来源信息。Android 正式签名需要维护者另行配置；本次没有复制源仓库 Secrets。

主分支的更新入口和发布脚本默认目标已指向本公开仓库。产品版本、协议、应用 ID、配置格式及会议行为保持不变。历史分支保留当时的运行逻辑与来源链接；合入主分支前应按当前公开仓库配置检查。

当前隐私检查覆盖拟迁移全部可达提交、树、文件对象、提交/标签消息与身份，以及三张生成的界面示例图。指定个人隐私目标及已测试编码变体未命中；凭据扫描未检出。不将此结论扩展为所有形式的秘密不存在或旧平台副本已擦除。原始规则、映射、恢复备份和本机证据保存在本机 Git 忽略的专用输出目录中，不随源码或安装包发布。
