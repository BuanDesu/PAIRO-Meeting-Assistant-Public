# 实际设备验收

自动化测试之外必须完成下列检查。请记录电脑系统、手机型号/Android 版本、程序版本与结果；未执行的项目保持未完成。

- [ ] 首次安装正式 APK；核对程序版本与 Release；安装下一个相同签名 APK，确认可以覆盖升级。
- [ ] 电脑同时存在 Wi-Fi、VPN、虚拟网卡时，选择正确地址；扫码填入后连接；电脑拒绝连接时手机不会收到画面。
- [ ] 首次请求相机权限、拒绝权限、返回取消、再次扫码；关闭扫码后相机指示灯熄灭。
- [ ] Windows 屏幕与窗口分别分享，取消选择不开始采集；停止分享后采集关闭。
- [ ] 麦克风与系统音频分别开启/关闭；手机听到预期声音；拒绝麦克风不影响仅画面分享。
- [ ] 手机锁屏 1 分钟后解锁、后台 1 分钟后返回；记录是否需点击声音按钮或重连。
- [ ] Wi-Fi 短暂断开恢复、切换网络、电脑服务重启；恢复或明确提示失败；主动断开后不自动重连。
- [ ] 连续会议 60 分钟；记录内存、耗电、画面与声音表现。
- [ ] 使用真实 AI 服务执行配置检测、截图问题、取消、失败重试；清空与离开后不显示迟到答复。
