# 项目修复记录（2026-10-12）

基于 GitHub main 的 c90a831 修复本地检查发现的问题，并恢复本地 Git 与远程仓库关联。

## 修复内容

- 信令服务验证 JSON 对象、SDP/ICE 结构及设备角色，处理 WebSocket 接收错误；非法 JSON 值和超大帧不会终止其他房间。
- Electron 屏幕权限兼容当前版本的 `media/[]` 与 `display-capture`；仍要求用户选择来源。限制权限及 IPC 为主窗口当前来源，取消选择时避免重复调用 Electron 回调。
- 房间离开、角色切换和清空对话时，取消模型任务并清除截图、上下文和旧答复。模型答复绑定发起时的连接，自动请求串行执行，队列最多 8 项。
- 模型请求设置 60 秒超时。浏览器请求使用 AbortController；Android 原生请求取消后忽略迟到结果，底层网络操作可能继续完成。
- 大消息按协商的 SCTP 上限分片，单片不超过 16 KiB；加入背压、4 MiB 消息/发送队列限制、接收顺序验证和 30 秒超时。桌面和手机需同时升级才能接收大截图。
- PeerConnection 初始化共用同一任务，断开使在途 ICE 配置/协商失效；对端离开会清理连接和远端媒体。待完成的屏幕/麦克风授权返回后会核对会话并关闭过期轨道。
- 桌面非秘密偏好由主进程写入稳定的 preferences.json；自动分配的信令端口与 API Key 不持久化。
- 恢复 GitHub 样式文件中被字面量截断占位文字破坏的完整 CSS；验证真实 electron-builder API 配置，补齐 Electron 下载和校验脚本，固定已验证的 Electron 版本。
- 更新开发依赖及必要的传递依赖覆盖，新增 Windows/Linux 自动测试和构建工作流，发布打包前运行测试，文档明确 Node.js 22.12+。
