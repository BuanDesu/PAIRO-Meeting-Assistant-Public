### 已知限制

- 屏幕分享、快捷键和语音识别受浏览器能力与权限影响；快捷键要求网页获得焦点。
- 语音识别可能调用浏览器供应商在线服务，不等同于本地离线转写。
- 默认 STUN 不能保证所有网络之间直连；需要 TURN 时应配置 ICE_SERVERS_JSON。
- 浏览器直连模型要求提供商允许跨域请求；不要在共享设备或不可信网页输入 API Key。
- 当前没有账号、持久化对话、项目级认证、TURN 凭据签发或生产级滥用防护。
