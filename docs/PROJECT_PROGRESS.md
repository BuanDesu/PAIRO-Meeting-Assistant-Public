## 已完成的能力

- Windows 屏幕或窗口分享、缩略图选择器、可选系统音频与麦克风、全局快捷键、局域网信令服务。
- Android 默认进入手机端；二维码配对、地址选择、连接检测、电脑允许手机加入后才传输媒体。
- WebRTC 加密媒体与分块消息；有限重连、协商超时、旧会话清理、服务心跳与资源限制。
- 截图框选、传输进度、手机解码后的接收确认；取消后释放本地预览与等待任务。
- 手机文本与截图提问、配置检测、队列、取消、重试、逐段显示回答；Android 原生 HTTP 流式请求，API Key 仅在当前会话内存中。
- 版本与标签一致性检查、APK 升级编号、发布附件校验、脱敏连接诊断；Windows/Linux 检查和从零生成 Android 工程的构建检查。

## 验证与待完成工作

当前自动化测试 81 项通过；生产界面与真实 Electron WebRTC 检查通过。Windows 成品和 Android 16 真机已验证扫码权限拒绝与恢复、加入审批、屏幕/单窗口/麦克风/系统音频、截图边界与手机回执、锁屏和后台、同房间更换来源、信令中断与服务重启、完整 60 分钟会话，以及电脑 Wi-Fi 暂断后 30 秒内自动恢复。真实 DeepSeek 配置、图片问答、逐段显示、取消、修正配置后重试、清空与主动离开均通过，未出现迟到回答或自动重新加入。正式包还验证了编辑后未失焦就关闭的设置保存。更新入口支持私有仓库提示；初始取消采集不生成房间并显示中文指导。ZIP 实际解压后的两次启动为 0.489 / 0.264 秒，测量范围见启动记录。
