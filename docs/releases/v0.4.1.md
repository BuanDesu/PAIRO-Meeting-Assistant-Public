# PAIRO v0.4.1

首个从清洗后的公开仓库重新构建的安装包版本。提供 Windows 便携 EXE、解压后直接运行的 Windows 目录 ZIP，以及 Android 正式签名 APK；没有复制或重新标记旧私人仓库的二进制文件。

会议功能沿用 0.4.0，应用 ID 与协议保持兼容。Android versionCode 为 4002，复用既有正式签名；旧正式版可覆盖升级。Windows 程序尚无 Authenticode 签名。两端建议同时更新。

Electron 更新为同主版本的 44.10.0，并更新兼容范围内的构建依赖，修复发布前依赖审计检出的已知问题。运行时下载继续固定官方 SHA-256，不使用未经校验的替代包。

每份包内含 `build-provenance.json`，记录真实源码提交、版本及固定组件版本。发布附件 `BUILD_PROVENANCE.json` 可与包内记录及标签提交交叉核对，`SHA256SUMS.txt` 校验三个安装包。源码构建前拒绝不一致的提交标识或已修改的跟踪文件。

本版重新执行单元测试、构建、签名与包内容检查；不将这些检查表述为重新完成真实设备、真实 AI 或一小时会议验收。
