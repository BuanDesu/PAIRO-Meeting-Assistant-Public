# PAIRO v0.5.0

本版将模型/API、会话上下文和本地知识库 RAG 放到电脑；手机仅负责配对、媒体接收和提词阅读。界面沿用既有风格，截图、选区、语音和电脑手动提问进入统一流程。Key 只在电脑本次运行内存中，不同步给手机。

**协议版本 5：电脑与手机必须同时更新，包括较早的 0.5.0 开发构建。** Android versionCode 为 5001，正式包复用既有签名；Windows 暂无 Authenticode 签名。

## 本阶段变更

- 电脑端新增模型设置、统一问题队列、上下文管理、提词快照同步和本地文件知识库导入/增量更新/词语检索。
- 离线语音支持中文/英文/自动模式、模型档位、VAD 与证据筛选；系统声音和麦克风分开排队，同源 FIFO、双源轮换。
- 停止共享释放媒体并保留当前房间与已批准连接；结束会话另行断开并清理提词。保留既有后台静默及回答键入保护。

## 已知问题与使用边界

- 中文长句中的术语、同音字仍可能误识别；长句可能分成多个问题，短答准确率仍有限。
- 经滤波或声学回声处理的跨源重复仍可能发生，不能保证全部去重。
- 持续高密度双源输入可能超过容量并暂停收听；处理已接收内容后可重新开启，或减少同时输入/选择轻量档。
- 知识库是有界的本地词语匹配，不保证同义词或跨语言语义命中；导入内容和命中片段会按明确操作发给配置的模型服务。

当前阶段按保留上述问题验收，未为发布新增产品优化。已有自动化、现场及实体麦克风/键入保护反馈用于阶段评估；真实设备上“同房间恢复后的手机画面”和“有声音时停止截止”两个完整场景的证据仍不足，不宣称全部覆盖。发布验证另包括干净提交重建、单元检查、签名/版本、来源和包内容校验；不将模拟检查当作新的真实设备业务验收。原始现场文本、录音、遥测、会话标识和诊断报告不随源码或安装包公开。
