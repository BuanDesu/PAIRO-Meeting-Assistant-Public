# PAIRO v0.3.0 · XP 会议工作台

电脑在后台投送问题，手机像一份持续更新的演讲稿一样展示回答。本版采用灰色立体边框、蓝色标题栏与红色警示的 XP 复古界面。

## 主要变化

- 手机底部切换“房间配对、API-KEY配置、会议助手”；会议助手固定竖屏，缩小输入栏，为回答保留更多阅读空间。
- 电脑底部切换“房间配对、投送窗口选择、快捷键设置”；准备好共享后可收起托盘，快捷键不自动弹窗、不抢焦点，回答只在手机显示。
- 默认小键盘 Num1 截图并自动提问；Num2 开关离线语音转写；Num3 切换主窗口内的文本输入栏；↑/↓ 控制手机阅读位置。可自行修改快捷键。
- 离线语音首次约下载 80 MB 组件，后续转写不需要语音服务 Key。普通会议混合电脑麦克风和系统声音，一对一会议只接收系统声音。中文识别结果统一为简体。
- 修复 Android 系统状态栏遮挡顶部标题的问题；真机确认键盘出现时输入栏和导航可见。

## 升级与开始使用

电脑和手机都需要更新到本版。正式签名 v0.2.0 手机包可以直接覆盖更新，地址与模型设置保留；API Key 仅在本次应用会话内存中，重新打开应用后需填写。

先让电脑和手机连接同一可信局域网，也可让电脑连接手机热点。电脑选择要分享的窗口，在手机扫码并连接，再由电脑允许加入。填写自己的 AI 服务地址、模型与 Key 后即可使用。使用 Num2 前，在电脑“快捷键设置”下载离线语音组件。

离线 tiny 模型按停顿或最长约 12 秒分段处理，嘈杂环境和口音可能影响准确性。音频只在本机转写；截图与转写文字在提问时发送至手机配置的 AI 服务。Windows 程序当前未签名。

## 验证范围

新界面、正式签名覆盖升级和五项快捷键均完成真机短验收；麦克风、系统音频转写及手机简体显示与自动回答通过。一对一模式未申请麦克风权限。另一网络／多活动网卡组合仍缺完整真机记录。
