# PAIRO v0.4.0 · 选中文字提问与回答键入

电脑继续在后台安静投送，手机负责显示 AI 回答。本版不再需要打开电脑主窗口输入问题。

## 新操作

- **Num3**：在其他程序选中文字，按小键盘 Num3，把选区发到手机自动提问。
- **Shift+Num3**：等手机回答完成，点击电脑中需要填写的普通输入框，再按 Shift+小键盘 Num3，逐字键入手机最新一条完整回答。选区、截图和语音提问的回答都适用。
- 中文默认 **60 字/分钟**，英文默认 **90 词/分钟**（每词按 5 字符折算）；可在“快捷键设置 → 回答键入速度”分别修改并保存。
- 按 **Esc**、再次按回答键入快捷键、切换窗口或输入焦点，都可停止。新问题、取消、清空和断连会撤销旧回答；生成中或最新请求失败时不会误填旧答案。
- 换行转为空格，不自动提交表单。键入完请自行检查内容并提交。密码框、只读框、管理员权限窗口和部分定制编辑器不支持此功能。

快捷键不会自动弹窗、抢焦点或播放回答。Windows 对 Shift+小键盘的翻页转换已作处理，不占用主键区 Page Down。旧版五键配置会补入新的回答键入快捷键。

## 更新后先做这几步

1. 电脑与手机**同时更新到 0.4.0**；手机安装 APK 覆盖现有正式包，无需卸载。Android 升级编号为 4001，沿用固定正式签名。
2. 电脑先退出旧程序，再替换 EXE 或完整解压新 ZIP；保留原程序旁的 `PAIRO-data` 文件夹。
3. 打开手机应用，重新填写 API Key（Key 仅在会话内存，不会随更新保存），检查已有地址和模型设置。
4. 在同一局域网重新配对，启用快捷键。先用一段不敏感的文字测试 Num3，再点击自己的测试输入框尝试 Shift+Num3；结束前可试一次 Esc 停止。

文件名继续沿用 `Pairo-Meeting-Copilot`，仓库名称为 `PAIRO-Meeting-Assistant`。Windows 程序当前没有代码签名证书。

## 验证范围

源代码的 100 项检查、隐藏窗口真实 WebRTC、原生 Windows 与普通网页输入框的选区、Unicode、速度设置、取消和焦点保护已通过。源码的 Windows/Linux/Android CI 通过；本次发布另验证安装包构建、签名、版本和 SHA-256。

本版手机的新快捷键业务流程、真实 AI 服务和实际问卷平台由维护者自行测试；不将以往版本的真机结果计作本版验收，也不重复未改变的长时会议流程。另一网络／多活动网卡组合、定制编辑器兼容性仍需按实际使用环境确认。
